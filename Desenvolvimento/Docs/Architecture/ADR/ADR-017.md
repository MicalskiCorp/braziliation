# ADR-017: Controle na Steam por emulação de gamepad, rebind no jogo e glifos próprios

- **Date:** 2026-11-09
- **Status:** Accepted
- **Context:** O ADR-006 centralizou todo input no `GameInput` sobre o action map, mas parou aí: o jogo não
  tinha tela de rebind, nem guardava bindings, nem integração com o Steam Input (dívida Alta no
  [`tech_debt.md`](../../Tech/tech_debt.md)). O Steam Deck Verified exige suporte completo a controle e
  glifos corretos. Havia dois caminhos. (A) Deixar a Steam entregar o controle como gamepad comum, no
  modo de emulação, que é o padrão dela para jogo sem a API, e resolver rebind e glifos no próprio jogo.
  (B) Integrar a API nativa do Steam Input pelo Steamworks.NET: glifos oficiais, mas o mapa de controles
  duplicado no formato de action sets da Steam e o rebind do controle feito na interface dela. O projeto
  ainda não tem nenhuma integração com o Steamworks.
- **Decision:** **Opção A**, decisão do responsável. O Unity lê o controle que a Steam emula, e nenhum
  código do jogo chama a API do Steam Input. O rebind acontece **dentro do jogo**, para teclado e controle,
  sobre `InputActionRebindingExtensions`. O `GameInput` é o único que toca o action map (ADR-006): aplica os
  overrides no boot, conduz o rebind interativo, restaura o padrão e informa a família do dispositivo
  ativo. Os overrides são **dado de configuração**: um JSON opaco (`SaveBindingOverridesAsJson`) guardado
  em `GameSettings` pelo `SettingsService`, no core puro. A UI de rebind só chama o `GameInput`. Os glifos são
  **nossos**, um conjunto por família (teclado/mouse, Xbox, PlayStation, Switch), escolhido pela família
  do dispositivo ativo, com uma preferência manual em `GameSettings` (Automático por padrão).
- **Consequences:** O projeto não depende do Steamworks para controle, e o rebind funciona igual fora da
  Steam. O preço é que, com o Steam Input ligado, todo controle chega como gamepad Xbox. Quem joga com
  um controle de PlayStation vê glifo Xbox no automático, e é para isso que existe a preferência manual.
  O Deck se apresenta como Xbox. Os critérios do Deck Verified aceitam glifo Xbox na falta do glifo do
  Deck, o que precisa ser conferido de novo na submissão. Os sprites de glifo viram asset de arte (skill `novo-asset`, `@SpriteArtist`). Rebind
  dentro do jogo exige tratar conflito de tecla, cancelar com Esc e não aceitar o mouse como binding de
  ação de movimento. Revisitar quando o Steamworks entrar no projeto por outro motivo (conquistas, nuvem),
  ou quando for preciso suporte completo ao controle de PlayStation (glifo e layout nativos, sem a escolha
  manual), como o responsável deixou registrado em 2026-11-09. Aí a API nativa passa a compensar, e os
  glifos oficiais podem substituir os nossos.

A galeria do claude.ai não tem pastas — os artefatos ficam numa lista única por data. Esta página é o agrupamento: a porta de entrada para a ficha de cada personagem, onde moram os sprites, as variantes, a animação rodando e o histórico do que mudou.

Como isto se mantém

Para a galeria não desandar conforme o projeto cresce.

  1. A lista de quem está aqui vive em Design/ArteFonte/IA/Paginas/galeria.json, no repositório.
  2. Cada ficha é gerada da spec do asset — não tem como mostrar arte velha.
  3. A URL de cada personagem fica no {asset}.pagina.json do context pack, e é nela que se republica. Personagem nunca ganha página nova: ganha versão nova da mesma página.
  4. Mudou arte ou entrou animação? py galeria_personagens.py regenera tudo e diz o que republicar.
